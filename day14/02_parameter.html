자바스크립트의 파라미터 특징 / 기능

  • 파라미터의 갯수와 상관없이 메서드명이 같다면 호출 가능
  • 파라미터의 개수가 불일치하여 받지 못하는 값이 있다면 undefined 처리
  • optional parameter
    값을 받아오지 못하는 파라미터가 undefined 처리가 되는 것을 막기 위해 기본값을 설정할 수 있음
  • 모든 파라미터는 arguments라는 프로퍼티를 이용해 파라미터를 관리
    arguments는 배열로 관리됨
  • optional parameter는 저장이 안 됨
  • optional parameter는 다른 파라미터보다 뒤에 와야 함
  • rest parameter : 남는 파라미터
    반드시 받아야 하는 파라미터는 일반 파라미터로 저장하고, 나머지 파라미터들은 통합하여 하나의 이름으로 배정
  • ... : spread 연산자
    배열이나 객체를 복제하는 데에도 사용 (얕은 복사)
