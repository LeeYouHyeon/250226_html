element 속성은 크게 두 가지 속성으로 구분
- 태그의 속성(attribute)
- css(style) 속성

  • 태그의 속성은 태그 자체가 가지는 속성이기 때문에 속성명을 그대로 사용
    tag.id, tag.name, tag.value, ...
  • class처럼 값을 여러 개 가지는 속성들은 별도의 명칭을 사용
    tag.classList
  • css 관련 속성들은 style.을 통해 접근 가능
    tag.style.color / tag.style.font-size (X)
  • font-size처럼 -는 인지 불가능. -를 지우고 camel cases로 변경
  • tag.style.fontSize, tag.style.backgroundColor
