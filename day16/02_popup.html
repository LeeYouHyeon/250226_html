window 메서드 종류

  • alert() / prompt() input 포함 / confirm() 확인/취소
  • window.open('url', window_name, option(size, scroll, ...));
  • window.close(); : 창 닫기
  • setInterval(function, millisecond);
    millisecond를 주기로 하여 지속적으로 function을 실행
  • setTimeout(function, millisecond);
    일정 시간 후에 function 실행
