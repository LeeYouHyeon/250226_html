DOM(Document Object Model) : html 문서 객체 모델

  • html 하위에 있는 모든 태그들(element) / 속성(attribute) = 프로퍼티 (property)를 가지고 있는 문서 객체
  • element를 가져올 때 getElementBy Id, ClassName, TagName
  • getElementById : 단일 element로 반환
  • getElementsByClassName, getElementsByTagName : 여러 elements 반환
    => HTMLCollection 타입
  • HTMLCollection 타입 : index를 사용하여 선택 가능
