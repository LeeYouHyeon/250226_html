Map
key : value 형태의 데이터를 하나의 배열로 만들어서 다시 배열에 저장

  • new Map()
    new Map([[key, value], [key, value], ...]);
  • map은 기본적으로 중첩 구조
    key는 중복 불가능
  • key를 식별자로 하는 get(key), set(key, value) 메서드를 제공
  • key는 문자로 하는 것을 원칙으로 함
  • delete() / has() / forEach() / keys() / values() / entries() / size / clear()
    forEach(v, k, self) : 파라미터 순서에 유의
    keys(), values(), entries() : MapIterator
