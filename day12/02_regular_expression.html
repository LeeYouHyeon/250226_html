정규표현식(Regular Expression)
문자 내에서 특정 내용을 찾거나 대체, 발췌하는데 사용

  • regExp로 많이 사용
  • 특정 데이터를 탐색, 확인, 존재여부를 쉽게 파악하기 위한 규칙
  • 웹 분야에서는 password, 첨부파일 규칙 등에 사용
    회원가입 외에는 자주 쓰이지 않음
  • 데이터 분석과 관련된 일을 할 땐 꼭 알고 있어야 함
  • 다른 언어에서도 거의 비슷한 방식으로 활용됨
  • /regExp/flag
    // : 시작기호, 종료기호
    regExp : 패턴, flag : 옵션
  • str.match(/regExp/flag) : str에서 매칭되는 부분들을 배열로 return. 없으면 null
  • str.replace(/regExp/flag, str2) : str에서 매칭되는 부분들을 str2로 변환
  • str.split(/regExp/flag) : 매칭되는 항목들을 기준으로 쪼개서 배열로 return
  • /regExp/flag.test(str) : 매칭되는 부분이 있는지 boolean으로 return
  • 정규표현식에 사용되는 플래그
  • i : 대소문자 구분 X
    g : 전역 검색
    m : 줄바꿈 포함
  • 패턴 문자열
  • a-zA-Z : 영어 알파벳
    ㄱ-ㅎ가-힇 : 한글
    0-9 : 숫자
  • . : 모든 문자열(숫자, 한글, 영어, 특수문자, 공백 포함 모든 것) : 줄바꿈은 제외
  • \d : 숫자 \D : 숫자가 아닌 것
    \s : 공백 \S : 공백이 아닌 것
    \w : 영숫자 \W : 영숫자가 아닌 것
    \특수기호 : \! \@ ...
  • 검색 패턴 : | or (|)
  • [] : or의 묶음 / 문자들 중 하나
    [jpg] : j or p or g
    /abc/ => 'abc'를 포함하는
    /[abc]/ => 'a', 'b', 'c' 중 하나를 포함하는
    /[a-z]/ => 알파벳 소문자를 포함하는
  • [^문자] : 각 문자를 전부 제외한 것
    [^abcd] : a, b, c, d는 제외
  • {min, max} : min~max개. 글자수 제한
  • ^ : 시작, $ : 끝
